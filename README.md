## GitHub Description

> 🚀 A modern and responsive **Digital Marketing Agency Landing Page & Portfolio Website** built from scratch using only **HTML, CSS, and Vanilla JavaScript**.
>
> This project features a professional agency-style interface with sections for **Services, Portfolio, Process, About, Careers, and Contact**, along with animated UI elements, modern typography, responsive layouts, CTA buttons, and a visually engaging hero section.
>
> ### ✨ Features
> - 🎯 Digital Marketing Agency Landing Page
> - 💼 Professional Portfolio Showcase
> - 📱 Fully Responsive Design
> - ⚡ Vanilla JavaScript Interactions
> - 🎨 Modern UI with animations & visual effects
> - 📊 Agency statistics / achievements section
> - 🔗 Call-to-action buttons
> - 🧭 Smooth navigation
> - 💻 No frameworks or libraries required
> - 🆓 **Free to use, modify, and customize**
>
> ### 🛠️ Tech Stack
> **HTML5 • CSS3 • JavaScript**
>

> ```text
